app/src/main/java/com/example/githubexplorer/ui/repodetail/FileTreeFragment.kt

修改位置

loadRepoTree() 函数内部（约第 113-120 行）

---

当前代码（错误）

```kotlin
val branchRef = RetrofitProvider.api.getBranchRef(owner, repo, branch)
val commitSha = branchRef.`object`.sha

val treeResp = RetrofitProvider.api.getTree(owner, repo, commitSha, 1)
```

问题：
getBranchRef 返回的 object.sha 是 commit SHA，而 getTree API 需要 tree SHA 或分支名。直接传 commit SHA 会导致 404，从而进入 catch 块，目录树无法构建。

---

正确做法

直接使用已经获得的分支名 branch 调用 getTree，因为 GitHub API 接受分支名自动解析到最新 tree SHA。

---

修改方案（精准替换）

步骤 1：删除以下两行

```kotlin
val branchRef = RetrofitProvider.api.getBranchRef(owner, repo, branch)
val commitSha = branchRef.`object`.sha
```

步骤 2：修改 getTree 调用参数

将

```kotlin
val treeResp = RetrofitProvider.api.getTree(owner, repo, commitSha, 1)
```

改为

```kotlin
val treeResp = RetrofitProvider.api.getTree(owner, repo, branch, 1)
```

---

修改后的完整 loadRepoTree() 函数（可直接替换）

```kotlin
private fun loadRepoTree() {
    val activity = requireActivity() as RepoDetailActivity
    val owner = activity.owner
    val repo = activity.repo
    binding.progressBar.visibility = View.VISIBLE
    lifecycleScope.launch {
        try {
            val repoInfo = RetrofitProvider.api.getRepo(owner, repo)
            val branch = repoInfo.defaultBranch ?: "main"
            activity.branch = branch

            // 直接使用分支名请求 tree，不再通过 getBranchRef 获取 commit SHA
            val treeResp = RetrofitProvider.api.getTree(owner, repo, branch, 1)
            treeNodes.clear()
            treeNodes.addAll(treeResp.tree)
            buildTree()
        } catch (e: Exception) {
            Toast.makeText(context, "Failed to load tree: ${e.message}", Toast.LENGTH_LONG).show()
        } finally {
            binding.progressBar.visibility = View.GONE
        }
    }
}
```
